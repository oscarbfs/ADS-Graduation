# Boletim de notas

Aplicação de terminal em Python para gerenciar disciplinas e notas, calcular médias e consultar o boletim. Permite adicionar, editar e excluir registros.

## Executar

Com Python 3 instalado, abra o terminal nesta pasta:

```powershell
python -m pip install tabulate
python main.py
```

Execute a partir desta pasta para que o programa encontre `database.txt`. Os dados são gravados ao escolher a opção **Sair** no menu.
