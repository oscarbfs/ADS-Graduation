# Estacionamento

Aplicação de console em Java com modelagem de estacionamento, veículos, clientes horistas e mensalistas e tickets.

## Executar

Com um JDK instalado, execute a partir da raiz do repositório:

```powershell
javac LPOO/desafio_1/*.java
java LPOO.desafio_1.Principal
```
