# Linguagem de Programação Orientada a Objetos

Exercícios e trabalhos em Java sobre classes, encapsulamento, herança, polimorfismo e interfaces.

## Conteúdo

- `atividade_1` a `atividade_9`: listas de exercícios, modelagem de objetos e pequenas aplicações, como delivery, agenda e jogo da forca.
- [Sistema bancário](atividade_programada/README.md): clientes e contas correntes e poupança.
- [Modelagem bancária](atividade_programada_2/README.md): pessoas físicas e jurídicas, contas e interface de saque.
- [Estacionamento](desafio_1/README.md): veículos, clientes e tickets.
- `avaliacao1_3questao`: modelagem de pessoas, empregados e fornecedores.
- `avaliacao2_3questao`: formas geométricas e interfaces.

## Executar

Utilize um JDK e uma IDE Java ou compile pelo terminal. Os arquivos declaram pacotes iniciados por `LPOO`; use a raiz do repositório como raiz dos fontes.

Exemplo de execução de um exercício, a partir da raiz do repositório:

```powershell
javac LPOO/atividade_1/questao_1.java
java LPOO.atividade_1.questao_1
```

Cada atividade é independente. Execute a classe que contém o método `main`.
