# Modelagem bancária

Exercício de orientação a objetos em Java com pessoas físicas e jurídicas, contas correntes e poupança e a interface `Sacavel`.

## Utilizar

Abra os fontes em uma IDE Java usando a raiz do repositório como raiz dos pacotes. Esta pasta reúne as classes de modelagem e não contém uma classe com método `main`.
