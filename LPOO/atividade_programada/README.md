# Sistema bancário

Aplicação de console em Java para praticar orientação a objetos com clientes, banco, contas correntes e contas poupança.

## Executar

Com um JDK instalado, execute a partir da raiz do repositório:

```powershell
javac LPOO/atividade_programada/*.java
java LPOO.atividade_programada.Interface
```
