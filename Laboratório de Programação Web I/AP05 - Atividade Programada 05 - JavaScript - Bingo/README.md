# AP05 — Bingo

Atividade de programação de um jogo de bingo em JavaScript, com página HTML e interação pelo navegador.

## Executar

Abra `bingo/index.html` no navegador. O código do jogo está em `bingo/app.js`. Acompanhe as interações e o console do navegador.
