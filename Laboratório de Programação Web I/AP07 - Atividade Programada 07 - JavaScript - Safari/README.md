# AP07 — Safári

Jogo de tabuleiro em JavaScript, com jogadores, lançamento de dado e casas com efeitos como avançar, voltar e perder uma rodada.

## Executar

Abra `index.html` no navegador. O código está em `script.js`; acompanhe as caixas de diálogo e o console do navegador.
