# Estrutura de Dados

Exercícios e atividades em C sobre memória, recursão e estruturas de dados.

## Conteúdo

- `atividade_1` e `atividade_2`: atividades introdutórias e cálculo de fatorial.
- `lista_exercicios1`: exercícios de ponteiros e listas.
- `atividade_avaliativa1`: lista duplamente encadeada.
- `atividade_avaliativa2`: fila e pilha.
- `atividade_avaliativa3`: árvore binária.
- `atividade_rato`: leitura de um arquivo de labirinto.

## Executar

Use um compilador C, como GCC. Exemplo, a partir desta pasta:

```powershell
cd atividade_2
gcc fatorial.c -o fatorial.exe
.\fatorial.exe
```

Compile cada exercício separadamente. A atividade do rato utiliza `conio.h` e deve ser executada na pasta que contém `labirinto.txt`.
