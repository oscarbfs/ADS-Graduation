# Classroom — Frontend

Interface em Angular 17 para autenticação, turmas, atividades, respostas e avisos de uma aplicação inspirada no Google Classroom.

**Tecnologias:** TypeScript, Angular Material e Bootstrap.

## Executar

Com Node.js e npm compatíveis com Angular 17, abra o terminal nesta pasta:

```powershell
npm install
npm start
```

Acesse `http://localhost:4200` e mantenha o backend em execução. O endereço da API está em `src/app/infra/configs/settings.ts`.

Para gerar o build:

```powershell
npm run build
```
