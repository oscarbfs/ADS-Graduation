# RECRUIT

Protótipo de portal de recrutamento desenvolvido para a disciplina de Interface Homem-Máquina.

Contém página inicial, apresentação da empresa, visão, vagas e formulário de candidatura.

**Tecnologias:** HTML e CSS.

## Visualizar

Abra `index.html` no navegador. As demais páginas são `aboutAndVision.html` e `candidacy.html`. O projeto contém a interface estática, sem backend para processar candidaturas.
